# PACE — браузерный прототип

Не требует сборки и npm-зависимостей. Из этой директории:

```sh
python3 -m http.server 8080 --directory dist
```

Откройте http://localhost:8080. ES modules требуют HTTP; открытие HTML через file:// не поддерживается. Автопроверка:

```sh
node --test core.test.mjs
```

## Возможности

- Ростер и редактирование имён/дивизионов; ручная запись завершённых и незавершённых попыток.
- Minor 5/3/1, Major 5/4/2; M/NS/процедуры −10; очки ограничены снизу нулём. HF = очки / время только для завершённой попытки.
- До 10 стрелков одновременно: последняя попытка текущего упражнения, сплиты или накопленное время, цвет и штрих, таблица графика. Первый сплит включает реакцию на сигнал.
- История, лучший HF каждого стрелка, тренировочная дуэль по последнему HF. Незавершённая попытка исключает определение победителя.
- Явно отмеченные демоданные 10 стрелков. Удаление всей базы требует подтверждения.

## Ограничения

Хранилище localStorage привязано к origin браузера. Экспортируйте JSON перед очисткой браузера. При ошибке записи интерфейс предупреждает о несохранённых данных. Повреждённое хранилище не перезаписывается автоматически. Импорт заменяет всю базу после подтверждения; максимум 5 МБ, 1 000 стрелков и 10 000 попыток. Один пользователь/вкладка; синхронизации и аккаунтов нет. Manrope загружается с Google Fonts с системным fallback при отсутствии сети.

BLE, синхронизация видео и нативный Excel пока не реализованы. Все времена вводятся вручную. Результаты предназначены для тренировочного сравнения, без официального расчёта процентов упражнения/матча и проверки одинакового дивизиона.

UI: белый/графит/оранжевый, боковая навигация на десктопе и компактная шапка на мобильном, адаптивная сетка. Разметка с labels, нативные модальные dialog и таблица как альтернатива SVG. Пользовательские строки выводятся через textContent.
