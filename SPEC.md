# PACE — согласованное ТЗ


## Core
- Свободная разминка без упражнения/матча; сравнение любых до 10 проходов, своих и чужих.
- Мини-матч до 10 стрелков и ориентировочно 12 упражнений. Название, бумага/сталь/no-shoot, зачётные попадания 2/1 по умолчанию с настройкой.
- Все проходы хранятся, тренер выбирает зачётный. Minor/Major 5/3/1 и 5/4/2; штрафы -10; очки минимум0; HF=очки/время. Очки упражнения пропорционально лучшему HF и максимуму упражнения; итог сумма. Без дивизионов, тренировочные результаты.
- До 5 таймеров параллельно с привязкой к рубежу. Основные Special Pie M1A2/M1A2+, далее CED7000 RF; другие по подтверждённой совместимости. Никаких придуманных BLE-протоколов.
- Отложенное назначение стрелка/упражнения. Исправления помечены, оригиналы сохранены.
- Телефон может дать старт/PAR и определять выстрелы; внешний таймер приоритетен.
- Оси X/Y графиков независимо: номер выстрела, время от старта, сплит. До10 выбранных проходов.
- Калькулятор до5 вариантов через +, ввод вручную/из прохода, изменения не меняют исходник.

## Видео
- Камера и галерея. Пользователь вручную выбирает видео из списка и проход из списка.
- Времена таймера основные. Автопоиск стартового писка, если нет уверенного сигнала — спросить время начала у пользователя.
- Без таймера поиск выстрелов по звуку; редактируемые метки, исходник сохраняется.
- Два видео, split-screen по умолчанию и прозрачный overlay; общий старт/seek, скорости .25/.5/1, покадрово; экспорт наложений.

## Совместная работа
- Тренер правит результаты, назначение и зачёт; стрелки добавляют видео/комментарии; участники видят всё.
- Офлайн автономные данные, последующее объединение либо локальная точка доступа планшета. Конфликты разрешает тренер, обе версии сохраняются.
- Видео у авторов либо полная копия на планшете. Публичная ссылка без входа включается для конкретной тренировки и включает результаты/видео/комментарии; удалённое обновление требует интернета.
- Экспорт XLSX/PDF, видео с наложениями, полный пакет для домашнего разбора.
- Большой экран: один проход или до5 параллельно, таблица/графики переключаемые.

## Данные и проверка
- Три предоставленных видео не связаны с CSV. Это примеры аудио, а не эталонные тайминги.
- Приоритет проверки рисков: настоящий протокол SpecialPie/прошивка и до5 соединений, фон/обрывы, аудио старта/выстрелов, Android12/16, обмен без интернета.

## Этапы
1. Core Android: локальная база, ввод, импорт, матч, графики, калькулятор; тесты и APK.
2. Видео импорт/камера/синхронизация и работа с двумя роликами; доказательная проверка аудио.
3. BLE квалификация на настоящих таймерах, затем сохранение и фон.
4. Локальный обмен/конфликты/права, отчёты и пакеты с медиа.
5. Публичный экран, экспорт видео и полевой прогон всей тренировки.

Незавершённые этапы обозначать явно. Исследования не равны подтверждённой аппаратной поддержке. Изменения вне ipsc-app не требуются.
