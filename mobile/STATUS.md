# PACE Android — этап разработки 18.10.2026

## Реализовано в первой сборке
- Стрелки, упражнения с 2/1 попаданиями по умолчанию и настройкой, ручной ввод/отложенное назначение, история правок.
- Minor/Major, HF, выбранный тренером зачётный проход и пропорциональные очки упражнений, тренировочная таблица одного мини-матча.
- PractiScore CSV импорт (сотые секунды, накопленные времена), идентификаторы для дедупликации; проверен предоставленный CSV 55 проходов / 4 стрелка.
- До10 проходов на графике с независимыми X/Y, табличные времена; калькулятор до5 сохраняемых вариантов и загрузка из прохода.
- JSON/XLSX/PDF экспорт результатов через системное «Поделиться». PDF использует локально упакованный OFL NotoSans, интернет не нужен; числовые XLSX ячейки остаются числами. JSON без медиа, не полный пакет тренировки.
- Видео: камера/галерея, локальные копии, ручная пара видео+проход, Android MediaCodec аудиопризнаки, поиск сигнала, ручная отметка старта и редактируемые кандидаты выстрелов без таймера. Два видео рядом/наложением с сохраняемым смещением. Метаданные защищены от перезаписи при повреждении.
- Старт/PAR телефона с Android звуковым сигналом; отмена таймера при выходе.
- Мультипротокольный реестр, BLE диагностика до5 подключений, выбор профиля и обнаруженной характеристики. Неизвестный протокол только raw; документированный legacy SpecialPie экспериментальный, требует явного подтверждения перед сохранением времён. Данные разных устройств не смешиваются, несохранённые серии сохраняются в памяти между стартами; выход предупреждает о потере памяти/разрыве подключения.

## Проверка
- Автотесты: расчёты, CSV/валидация, атомарность/восстановление, сохранность калькулятора, XLSX/PDF/JSON, синтетический beep, повреждённые видеометаданные, фрагментированные BLE-пакеты/изоляция/дедуп, навигация/график и 320px viewport.
- 31 автотест прошёл; `dart analyze lib`: No issues found. `flutter build apk --debug --no-pub` завершился успешно. Установочный файл `../releases/PACE-0.1-debug.apk` (debug-подпись, только разработка). Совместимость установки по манифесту Android проверена через aapt, runtime на целевых устройствах не выполнялся.
- Оригинальные видео молча исследованы ffmpeg+stdlib; предположительные начала сигнала .460 / 1.260 / 2.240 с не являются ручной эталонной разметкой. Нельзя оценить точность/recall по этим данным без подтверждения.

## Следующие этапы согласованного ТЗ
1. Квалификация протоколов и прошивок на настоящих SpecialPie; CED RF требует отдельного транспорта/приёмника, BLE не обещан.
2. Фоновый сбор, автосохранение всех BLE серий и восстановление при обрывах, назначения рубежей, полноценный живой экран до5 потоков.
3. Микрофонный таймер в реальном времени, покадровое сравнение и рендеринг экспортируемого видео с оверлеями; полевые критерии аудиоанализа.
4. Несколько тренировок/мини-матчей, комментарии, права участников/тренера, локальный обмен/слияние конфликтов.
5. Полный пакет данных+видео с безопасным восстановлением, PDF/XLSX итоговой матчевой таблицы и расширенные отчёты.
6. Публичный экран/ссылка, внешняя публикация по включению для тренировки, затем iOS.

Наличие кода/успешного APK не подтверждает фактическую точность BLE, камеры, воспроизведения и микрофона на целевой аппаратуре. Это сборка разработки, не завершение всего ТЗ.

Настраиваемые чувствительность, минимальный интервал, фильтр эха (слабый повтор в окне80–400мс), сигнал150–1500мс и уровень10–100%. Стартовый2300Гц тон отбрасывается по тональности; это не подтверждённая полевая точность.
- Вместо ToneGenerator короткой фиксированной огибающей — AudioTrack PCM. Системная громкость не меняется; отображается реальная громкость медиа. PAR завершает звук после остановки микрофона. Микрофон освобождается при уходе/фоне.
- TimerSession принадлежит Home, а не экрану. Переходы между разделами не отключают BLE. Серии сохраняются автоматически на stop/newstart/manual finish/link loss; уникальные ID и очередь записи защищают от дублей/гонок. Завершение вручную не останавливает соединение.
- ConnectedDevice foreground service+уведомление+wakelock для приёма с выключенным экраном. При уничтожении процесса/смахивании приложения соединение не восстанавливается. Работа на реальном устройстве ещё не подтверждена.
- Крупный live и полноэкранный режим с единицами с; полноценные времена/сплиты и история.
- X по умолчанию время от старта (с), Y номер выстрела; числовые подписи, значения при касании и полноэкранный график. Кнопка «Видео» всегда видна в нижнем меню; остальные разделы через «Ещё».

## Видеоразбор 0.2.0 (18.10.2026)
- Образец: https://workspace.ru/cases/hitfactor-shots-analysis-prilozhenie-dlya-trenirovok-po-prakticheskoy-strelbe/ — изучены описание и экраны сравнения. Реализована структура сценария в интерфейсе PACE; модель нейросети и её метрики не перенесены.
- Дорожки A/B с выстрелами, общей шкалой секунд, масштабом1/2/4, scrub/seek, переходами к соседним выстрелам, сплитами и разницей накопленного времени. Таблица сравнивает номера выстрелов, соответствие мишеней проверяет тренер.
- Отдельные пары видео+проход и старты A/B. Сигнал/первый выстрел можно отметить вручную; при отсутствии найденного сигнала спрашивается время начала. Поправка B хранится отдельно от стартов; legacy offset мигрирует без потери старых связей. Проверено изменение B отдельно и повторное открытие сравнения A.
- Два видео: вертикально на узком телефоне, рядом на планшете/широком экране; прозрачное наложение0–100%, полноэкранный разбор. Стрелки шагают по номинальной частоте кадров, точный seek зависит от кодека/VFR, не гарантируется кадровая точность.
- MP4 H264/AAC с прожжёнными временем, номером выстрела и сплитом: один ролик, два рядом, прозрачное наложение. До1920×1080/1080×1920 без увеличения исходного разрешения, локально через Android Media3 Transformer1.8.0. В парном экспорте trim по общему старту, окончание по более короткому ролику, звук только A; поддержана тонкая поправка B. Отмена/закрытие удаляют частичный файл.
- Vivo: пользователь вручную обновил0.1.2+3, установленная версия подтверждена,2 прохода (9/11 выстрелов) сохранены. На момент проверки0.2.0 vivo отключён;0.2.0 на нём пока не установлен/не проверен.
- Автоаудиоанализ остаётся эвристическим: кандидаты требуют подтверждения. Собственная обученная офлайн-модель, заявленная точность HitFactor, VFR/HEVC/HDR/10мин stress, полный экспорт тренировки с медиа и совместный офлайн-обмен этой версией не квалифицированы.
