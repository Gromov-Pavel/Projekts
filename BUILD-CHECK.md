## Подтверждено на устройствах

- Прямой BLE-поиск в версиях до 0.2.2 не распознал телефон. Часы видели 9–15 соседних устройств; добавление короткой метки не решило проблему. Этот транспорт заменён штатной связью Zepp Side Service.
- В старой Android-реализации обнаружен дополнительный баг: GATT server получал события о подключённом Special Pie и ошибочно назначал таймер часами. В текущем транспорте назначения по этим событиям нет.
- На Vivo установлен Android 0.5.1+18 без удаления данных. Установленный Zepp 10.9.0 разрешает HTTP внутри телефона своей исходной network_security_config; настройка не менялась.
- Реальный loopback-мост проверен через локальный ADB forward: до одобрения отдаёт только код; команды запрещены; чужой клиент получает 409; неизвестный путь/неверный служебный заголовок отклоняются; после истечения heartbeat одобрение закрыто. Использованный временный forward снят.
- Пользователь прочитал шестизначный код с часов; он совпал с кодом на Vivo. Подтверждение выполнено, после него телефон показал «Часы подключены». Этот статус сохранился при переходах между экранами.
- На часах выбран режим «Всю тренировку»: он сохраняет экран и обмен активными. В режиме «Только во время прохода» сон экрана может остановить heartbeat и потребовать повторного подтверждения.
- На физической паре 0.5.0 / 0.3.0 пользователь запустил таймер с часов и услышал сигнал. Завершение тоже дошло: на Vivo зафиксировано «Завершено с часов», 21,64 с, выстрелов 0. Пользователь отметил, что завершение срабатывает не с первого нажатия. Исправление 0.5.1 / 0.3.1 включает очередь завершения во время подтверждения старта, увеличенную кнопку, ограниченный повтор доставки и идемпотентность остановки; повторный аппаратный прогон выполнен: пользователь подтвердил «Да, с первого нажатия». На телефоне подтверждены «Часы подключены» и выбранный источник «Таймер телефона». При последующем чтении UI серия уже сохранена: 6,11 с, одна отметка 0,68 с. Само нажатие завершения подтверждено пользователем; промежуточный экран «Завершено с часов» в этом повторе не снят.
- Special Pie сейчас не найден по своему имени при повторном поиске. Посторонние устройства не выбирались; реальные выстрелы и одновременная работа нескольких таймеров в этой сессии не проверены.

- Проверка команд проводилась по инструкции без выстрелов, однако в сохранённой серии есть одна звуковая отметка. Причина (окружающий звук, эхо сигнала или другое событие) не установлена. Этот прогон не подтверждает точность микрофонного распознавания.

- Vivo показал предупреждение «Обнаружен опасный вирус» для 0.4.3. Причина не установлена, ложным оно не объявлялось. Подпись совпала, зависимости и разрешения Android тогда не менялись; пользователь явно разрешил продолжить диагностику. Защита телефона не отключалась.
- Входящие данные и команды идут только через локальный адрес телефона и связанный Zepp; сервер не слушает LAN. До кода нет результатов; команда требует текущей сессии, прохода и возрастающего ID. Фоновый/закрытый телефонный таймер не стартует.
- Для самого Special Pie outgoing Start/Stop не подтверждён; неизвестные пакеты не отправляются.
- Видео, данные устройств, ключи подписи, резервные копии и диагностические дампы в Git не включены.
