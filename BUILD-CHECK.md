# Сборка Android и часов — 2026-10-24

Ветка объединяет Android из ipsc-cloud-transfer-20261024 (44d626c) и проект часов
ipsc-watch версии 0.1.0. Android-код и версии зависимостей не менялись.

Workflow .github/workflows/build-apps.yml запускает независимые jobs Android и Zepp.
Android: Flutter stable, проверка lockfile без обновления, анализ lib, все тесты,
debug APK. Если stable SDK старее требований проекта Dart >=3.13.5 / Flutter >=3.47.0,
разрешение зависимостей остановится: не понижать ограничения без отдельной задачи.
Часы: Node 22, 8 тестов модели/экрана. Сборка Zeus исключена до разрешения внешней передачи.
Артефакты появляются только после успешных сборок в GitHub Actions.

APK получает debug-подпись машины сборки. Она может отличаться от подписи APK,
установленного на vivo; такой APK нельзя обновлять через uninstall с потерей данных.
Для безопасного обновления нужна исходная подпись из локального окружения Mac.
Ключи подписи не загружать в публичный репозиторий.

В текущей облачной среде нет Flutter и Android SDK. Попытка загрузить официальный
каталог Flutter SDK вернула HTTP 404. Java 17 доступна с явным путём к библиотекам.
Сборку Zeus повторно пробуют на Node 22 после ошибки сетевого клиента CLI на Node 24.

Наличие двух пакетов не означает готовую интеграцию: часы 0.1.0 используют только
демопоток; задержка/случайный диапазон, кнопка Старт/Завершить и реальный транспорт
обсуждены, но в код этой версии не добавлены. Прошивка M1A2+ требует проверки.
В mobile/lib/timer_protocol.dart legacy-декодер обрабатывает F8 F9 18 <session> F9 F8
как TimerEventKind.stop; тест timer_protocol_test.dart покрывает это. Это доказательство
логики в исходниках, не аппаратная квалификация пакета на таймере пользователя.

USB vivo и часов из облака недоступен. Установка, реальные BLE, сигнал, задержка,
сохранность пользовательских данных и точность аудио не проверялись в этой попытке.

Автоматическая проверка безопасности заблокировала дальнейшую сборку Zeus из-за
возможной передачи проекта во внешний сервис Zepp. Сборка часов также удалена из CI,
чтобы не обходить блокировку. Установочный пакет часов в этом запуске не ожидается.
