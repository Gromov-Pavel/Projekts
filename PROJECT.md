# PACE — IPSC training

ТЗ согласовано пользователем 18.10.2026; разработка разрешена. Источник требований — SPEC.md (включая ручной выбор пары видео+проход, до10 проходов разминки/графика, до5 калькуляторных вариантов, до5 таймеров).

## Структура
- mobile/: Flutter Android приложение, текущая разработка.
- prototype/: ранний браузерный черновик, не отражает всё согласованное ТЗ.
- research/: проверенные источники о таймерах, диагностический анализ примеров видео.

## Аппаратура
- Основные таймеры Special Pie M1A2/M1A2+, далее CED7000 RF. RF не равен BLE. Поддержка устройств проверяется отдельно по модели/прошивке.
- Техническая основа: офлайн Android без обязательного аккаунта, затем обмен/публичный экран и iOS.

## Работа с контекстом
Читайте SPEC.md, затем README нужного модуля и только изменяемые файлы. Не перечитывайте целиком историю/вставленный диалог поисковика. Его примеры кода не подтверждают работающую интеграцию.
Агенты получают отдельные файлы и краткий handoff: результат, доказательство, пробел, следующий шаг. Ponytail full. Не переносите VK QA scope из родительского рабочего каталога в приложение.

## Проверки
Из mobile/: `flutter test`, `dart analyze lib`, `flutter build apk --debug`.
Состояние этапов и ограничения фиксируются в mobile/STATUS.md.
