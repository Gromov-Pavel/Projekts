# IPSC тренировОчка — часы 0.2.0

Amazfit T-Rex 3 Pro 48 мм, Zepp OS API 3.0+, Android 0.4.0+13.

Работа без интернета: часы в роли BLE Central подключаются к Android GATT Peripheral. Zepp Side Service для обмена результатами не требуется. Интернет и вход Zepp нужны для стандартной доставки тестового пакета через preview/QR.

## Подключение

1. Обновить APK телефона, сохранив данные.
2. В телефоне открыть «Ещё → Настройки/Данные → Подключить часы», включить связь и выбрать источник.
3. На часах запустить приложение, нажать «Подключить». Подтвердить системное Bluetooth-сопряжение, если предложено. Сверить шестизначный код на обоих экранах и на телефоне нажать «Код совпадает — разрешить».
4. Для внешнего таймера выбрать один подключённый поток в настройках таймера и включить приём. Его события автоматически обновляют часы.
5. Для управления телефонным таймером заранее выбрать источник «Таймер телефона», затем открыть «Тренировка → Таймер телефона» и оставить приложение открытым. Часы: «Старт» → «Отмена» во время задержки → «Завершить» во время прохода. Завершение с часов сохраняет серию. При несохранённой/ошибочной серии продолжить на телефоне.
6. После разрыва снова подключиться и подтвердить часы. При устаревших данных кнопки не отправляют команды.

Удалённое управление Special Pie не подтверждено и заблокировано. Используйте физические кнопки таймера, старт/выстрелы/конец приходят на часы через Android.

## Установка на часы

В Zepp телефон и часы должны быть связаны. Zepp → Профиль → Настройки → О приложении → 7 раз нажать значок Zepp. Затем включается режим разработчика со сканированием QR.

На Mac: `zeus preview --target trex3pro48`, авторизоваться в открытой странице Zepp, получить установочный QR и сканировать из режима разработчика Zepp. Официальная инструкция тестового preview не требует предварительной регистрации приложения: https://docs.zepp.com/docs/guides/quick-start/preview/ . appId 1100001 пока оставлен тестовым; публикация в магазине не выполняется. Если сервер Zepp потребует назначения appId, это отдельный ответ сервиса — не менять номер на случайный.

`.zab` — пакет часов, не APK. Само копирование .zab на телефон не устанавливает приложение.

## Проверка

`npm test` — тесты модели, транспорта с подменой BLE API, UI и общего с Dart wire-вектора. `zeus build` — сборка. Эти проверки не доказывают совместимость Bluetooth на конкретной прошивке и не заменяют реальную установку.
