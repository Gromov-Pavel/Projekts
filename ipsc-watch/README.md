# IPSC тренировОчка — часы, 0.1.0

Исходный проект приложения Zepp OS для Amazfit T-Rex 3 Pro 48 мм, 480×480.
Целевое устройство пользователя: Zepp OS 6, прошивка 6.3.13.5.

## Что работает в коде
Главный экран времени, сплита и числа выстрелов; демонстрация шести выстрелов;
настройка «не гасить всю тренировку / только во время прохода», сохраняемая на часах.
Демо запускается вручную и явно подписано. Время означает время последнего
выстрела от старта, не локальный бегущий секундомер. Для первого выстрела сплит — «—».
Настройки экрана действуют на странице тренировки; при выходе системная политика возвращается.

## Проверка и сборка
Node.js: `npm test`. Для сборки нужен официальный Zepp OS Zeus CLI.
Установить CLI по актуальной документации Zepp OS, затем в этой папке: `zeus build`.
Перед установкой зарегистрировать приложение в Zepp Developer Console и заменить
тестовый appId 1100001 в app.json своим назначенным идентификатором.
appId в этом проекте — локальная заглушка, не зарегистрированное приложение.
Проверить в Zepp Simulator и на реальных часах, затем выполнять установку через
режим разработчика Zepp по официальной инструкции. ZIP — исходники, не установщик.

## Следующая интеграция
Приёма данных по Bluetooth в этой версии нет. @zos/ble предоставляет штатную связь
с Side Service внутри Zepp на телефоне; это не готовое API для произвольного Flutter APK.
Нельзя считать, что наша Android-программа уже может отправлять данные в этот канал.
Сначала исследовать и проверить мост между Android-программой и часами:
вариант BLE GATT отдельно либо Zepp Side Service с доступным локальным источником.
Ни один вариант ещё не выбран и не квалифицирован. Интернет для продукта не допускается.
После выбора транспорта подключить декодированные снимки к acceptSnapshot и render.

См. docs/protocol.md. Таймер должен действительно выдавать live-выстрелы;
если он передаёт серию только после завершения, часы не получат выстрелы раньше телефона.
Завершение прохода должно приходить явным событием; пауза между выстрелами не означает конец.

Не проверены на устройстве: установка, шрифты/раскладка, сохранение настроек,
поведение экрана, Bluetooth, задержка и работа без сети. Тесты модели не заменяют эти проверки.

## Фактические проверки в облаке
8 тестов пройдены (Node.js 24): модель и сценарий экрана с подменённым Zepp API.
Синтаксис JavaScript проверен. Это не запуск в Zepp Simulator.
Zeus CLI 1.9.3 установлен; в его пакете пришлось восстановить ссылку на вложенный
zeppos-app-utils. Сборка заблокирована HTTP 502 при обновлении каталога устройств
с upload-cdn.zepp.com. Установочный .zab не получен.
