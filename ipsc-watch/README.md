# IPSC тренировОчка — часы 0.9.0

Amazfit T-Rex 3 Pro 48 мм, Zepp OS API 3.0+, Android 0.9.0+23.

По умолчанию часы используют штатный канал Zepp Side Service, который обращается к 127.0.0.1:19373 внутри телефона. Команды и результаты не отправляются в интернет. Для этого режима Zepp должен работать и быть связан с часами.

Добавлен отдельный режим **Напрямую к таймеру**: шестерёнка → Подключение таймера. Он использует BLE часов без телефона. Перед поиском отключить таймер от телефона. Библиотека, инструкция и ограничения аппаратной проверки — [timer-support.md](../docs/timer-support.md). Прямой режим пока не переносит проходы в историю телефона; для сохранения истории использовать режим Через телефон.

## Подключение

1. Установить Android поверх текущей версии и часы через официальный Zepp Preview QR.
2. На Vivo: Ещё → Настройки/Данные → Подключить часы → включить связь.
3. Открыть приложение часов: соединение начинается автоматически. Один раз сверить код на часах и телефоне и подтвердить совпадение на телефоне. Дальнейшее открытие приложения часов не требует нового кода, пока сохранена пара.
4. Для сброса пары использовать «Забыть часы». Новое устройство и очистка данных требуют новой сверки.
5. Источник выбирается автоматически: подключённый выбранный внешний таймер, иначе другой подключённый, иначе таймер телефона. До запуска телефона IPSC должен находиться на переднем плане.

## Управление

- После потери прямой связи часы автоматически восстанавливают подключение сохранённого таймера, пока рабочий экран открыт. Последний результат остаётся видимым. Прерванная серия отмечается неполной; пропущенные выстрелы не дозагружаются. Подробности — [восстановление связи](../docs/timer-reconnect.md).

- Большая шестерёнка без фона открывает настройки экрана и задержку старта для телефонного таймера. Внутри «Задержка» выбираются фиксированное значение или случайный диапазон 0–60 секунд (начальный диапазон 3–6 секунд). Нижняя/верхняя границы сохраняются, новое случайное значение выбирается один раз на запуск. Задержка применяется вместо задержки телефона для текущего запуска. Special Pie использует собственные сохранённые настройки задержки.
- Нижний сегмент: зелёный «СТАРТ», красный «Стоп», отдельные подписи подключения и ожидания. Для неподдерживаемого внешнего протокола управление не разрешается.
- Для распознанного Special Pie M1A2 реализованы старт/остановка через FFF2; формат описан в [протоколе управления](../docs/special-pie-control.md). На собственном Special Pie пользователя старт и остановка подтверждены физически (Android 0.9.0 / часы 0.6.0). Совместимость со всеми прошивками и точность выстрелов/сплитов отдельно не проверены.
- Телефонный «СТАРТ» сам открывает экран таймера в IPSC и запускает сигнал. В фоне микрофон не запускается. «Стоп» завершает серию; при появлении внешнего устройства текущий телефонный проход не переключается посередине.
- Подтверждение доставки команды не означает фактическое начало серии. Старт/финиш отображаются по состоянию источника; автоматического повторного старта нет.
- Режим «Экран: всю тренировку» удерживает экран активным. В режиме только прохода сон может приостановить обмен; после пробуждения сохранённая пара подключается автоматически с новой сессией.

## Установка часов

Zepp → Профиль → Настройки → О приложении → 7 раз нажать значок Zepp. Затем Устройства → T-Rex 3 Pro → Режим разработчика → + → сканирование.

Из проекта: `zeus preview --target "Amazfit T-Rex 3 Pro (48mm)"`. Пакет .zab не устанавливается Android-установщиком. appId 1100001 тестовый, публикация в магазине не выполнялась.

Зависимость @zeppos/zml 0.0.43 — официальная библиотека Zepp (Apache-2.0). Установка: npm ci. Проверки: npm test. Текущие результаты и ограничения — [BUILD-CHECK](../BUILD-CHECK.md).
