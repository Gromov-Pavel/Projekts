# IPSC тренировОчка — часы 0.5.0

Amazfit T-Rex 3 Pro 48 мм, Zepp OS API 3.0+, Android 0.7.0+20.

Связь идёт штатным каналом приложения часов и Zepp Side Service. Side Service обращается только к 127.0.0.1:19373 внутри этого телефона. Отдельный поиск телефона как BLE-периферии не используется; интернет для результатов и команд не нужен. Zepp должен работать на телефоне и быть связан с часами.

## Подключение

1. Установить Android 0.7.0+20 поверх текущего приложения.
2. На телефоне: Ещё → Настройки/Данные → Подключить часы → включить связь.
3. На часах: Настройки → Всю тренировку → Назад → большая кнопка Подключить. Этот режим сохраняет экран и обмен активными всю тренировку. В 0.3.1 экран также автоматически удерживается во время сверки кода и выполнения команды. В режиме только прохода сон экрана может приостановить обмен; после потери heartbeat создаётся новая сессия; сохранённая пара подтверждается автоматически.
4. Сверить шестизначный код на двух устройствах. На телефоне нажать «Код совпадает — разрешить» только при совпадении.
5. Внешний таймер: выбрать подключённый Special Pie и включить приём в его настройках. На часы передаётся один выбранный поток. Дистанционный старт самого Special Pie не подтверждён; использовать его физические кнопки.
6. Таймер телефона: выбрать его источником для часов и открыть Тренировка → Таймер телефона. Старт с часов запускает установленную задержку; Отмена отменяет подготовку; Завершить останавливает и сохраняет непустую серию. Экран таймера телефона должен оставаться открытым.

До подтверждения передаётся только код. Команды связаны с сессией одобрения и текущим проходом. Старые данные не разрешают управление, после прекращения обмена одобрение отзывается.

## Установка часов

Zepp → Профиль → Настройки → О приложении → 7 раз нажать значок Zepp. Затем Устройства → T-Rex 3 Pro → Режим разработчика → + → сканирование.

Из проекта: `zeus preview --target "Amazfit T-Rex 3 Pro (48mm)"`. После входа Zepp выдаёт QR; код можно показать отдельным изображением. Пакет .zab не устанавливается Android-установщиком. appId 1100001 тестовый, публикация в магазине не выполнялась.

Зависимость @zeppos/zml 0.0.43 — официальная библиотека Zepp (Apache-2.0), используется вместо самостоятельной реализации транспорта. Установка: npm ci. Проверки: npm test. Актуальная аппаратная проверка и ограничения — BUILD-CHECK.md в корне репозитория.

Экран 0.4.0: шестерёнка сверху, основная кнопка в нижнем сегменте. Зелёный «Старт», красный «Стоп»; в отсутствие связи та же кнопка подключает часы.

В 0.4.1 внешний таймер явно показывает готовность, активную и завершённую серию. Число 0.00 без выстрелов означает отсутствие времени выстрела, а не потерю соединения.

В 0.4.2 надпись готовой основной кнопки — «СТАРТ». Удалённый запуск внешнего таймера этим изменением не добавлен.

Автосвязь 0.5.0: при открытии часы подключаются сами. Один раз сверьте код на часах и телефоне и подтвердите на телефоне. В дальнейшем повторная сверка не нужна, пока пара сохранена. «Забыть часы» в IPSC отзывает ключ. Связь должна быть включена в IPSC, Zepp должен работать.
