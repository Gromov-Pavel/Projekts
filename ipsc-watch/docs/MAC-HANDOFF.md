   Штатный @zos/ble связывает часы с Zepp Side Service, а не с произвольным APK.

## Android: продукт и требования
Flutter, package app.pace.ipsc_training. Название строго «IPSC тренировОчка».
Android-first, обязательна работа без интернета. До 10 стрелков, около 12 упражнений,
до 5 внешних таймеров. Тренер управляет планшетом; участники видят все результаты.
Желательны просмотр с телефонов и общий экран, локальная сеть через точку доступа допустима.
Устройства: vivo X300 Pro V2502A, Android 16; Samsung SM-T500, Android 12 со слов пользователя.

Таймеры: Special Pie M1A2/M1A2+ в приоритете; CED 7000 с RF. Мультипротокольная
архитектура; совместимость подтверждать только на реальном устройстве. Пользователь
раньше успешно принимал проход со своего Special Pie. Последнее обновление не
квалифицировало заново реальную стрельбу, BLE и точность аудиодетектора.

Тренировка: таймер без обязательного упражнения, крупный live-результат, выстрелы,
первый выстрел и сплиты. Непрерывный приём серий внешнего таймера без переподключения.
Телефонный таймер: чувствительность, фильтр эха, задержка/PAR, громкий сигнал.
Крупный UI для перчаток и переключаемый полный экран.

Упражнение: название, бумага, сталь, зачётных попаданий на мишень, no-shoot;
очки IPSC Major/Minor, дивизионы не нужны.
Матч: участники, упражнения, несколько проходов; один зачётный по умолчанию,
ручная замена тренером. Итоги по матчу/упражнениям: очки и проценты.
Архив, экспорт, новый матч с сохранением истории.
Графики: до 10 выбранных проходов разных стрелков; X — время от старта,
Y — номер выстрела. Подписи осей, оси в шестерёнке; tooltip: стрелок, время,
сплит, номер выстрела. Фильтры по стрелку, упражнению, дате.
Калькулятор: сохранённый исходный проход и до 5 предположений, сравнение хит-фактора.
Видео: пользователь выбирает видео и проход из списков. Поиск сигнала старта и
выстрелов с подтверждением/ручной коррекцией; неуверенный старт уточнять.
Два видео по собственным стартам, рядом или наложением. Полный экран A слева/B справа,
общий пуск и перемотка, скорость в шестерёнке, звук внутри плееров.
HUD: время, текущий/общий номер выстрела, последний сплит. Экспорт MP4.
Автометки не выдавать за данные таймера или обученную модель.

## Android: переданное состояние реализации
Нижняя навигация: Трен. (tooltip «Тренировка»), Матч, Графики, Видео, Ещё.
Ещё: Проходы, Калькулятор, Настройки/Данные. Таймер подключается в настройках.
В заголовках только имя экрана.
На тренировке стрелок/упражнение задаются для новых ручных, микрофонных и внешних
проходов. Контекст захватывается при сохранении серии, старые проходы не меняет.
Выбор общий для таймеров на текущий сеанс; назначений на отдельные таймеры пока нет.
Настройки телефонного таймера сворачиваются. История сгруппирована по датам со
сворачиванием, импорт PractiScore CSV внизу, проходы добавляются в матч.
Матч: автоматический первый зачётный с сохранением ручной замены, сгруппированный
выбор проходов, таблицы итогов, блоки упражнений/участников, XLSX/PDF/JSON экспорт.
Новый матч архивирует упражнения, сохраняет участников/проходы. Архив только для
чтения, итоги и XLSX. JSON совместим с ранним архивом.
Видео A/B — отдельные карточки со статусом старта/синхронизации.
Кнопка съёмки видео удалена по просьбе пользователя.

Последняя Android-версия 0.3.1+12. В форме результата «Остальное — Альфы»:
A = paper × hitsPerPaper + steel × hitsPerSteel − C − D − Miss.
Без упражнения отключена; повторное нажатие заменяет A. Пустые C/D/Miss → 0;
отрицательные, дробные, избыточные значения дают ошибку и не меняют A.
No-shoot/процедурные штрафы отдельно. Сохраняет только отдельная кнопка «Сохранить».
Исправлено раннее освобождение TextEditingController при активной клавиатуре:
DialogRoute и ожидание route.completed, ошибки рядом с кнопками.
10 widget-тестов пройдены, dart analyze lib/main.dart без замечаний.
APK собран/подписан и установлен adb install -r на vivo; dumpsys подтвердил
versionName 0.3.1/versionCode 12; 4 файла данных сохранили SHA-256.
Саму новую кнопку вручную на устройстве не квалифицировали.
