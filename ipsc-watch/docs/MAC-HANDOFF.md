# Продолжение — 25.10.2026

Рабочая ветка codex/watch-phone-bridge-20261024. Текущий транспорт — Zepp Side Service и loopback Android, версии 0.5.1+18 / 0.3.1. Прямой BLE-поиск на физической паре не распознал телефон, поэтому заменён официальным SDK @zeppos/zml.

Пользователь прочитал код с часов; он совпал с кодом на Vivo, после подтверждения телефон показал «Часы подключены». Для проверки выбран режим часов «Всю тренировку». В режиме «Только во время прохода» сон экрана может приостановить heartbeat и потребовать повторного подтверждения.

Инструкции — README.md, протокол — docs/protocol.md, квалификация и ограничения — BUILD-CHECK.md в корне. Не выдавать unit-тесты за реальные выстрелы/команды. Сохранять пользовательские видео и данные, не публиковать диагностические дампы устройства и ключи подписи.
