# Текущее продолжение — 24.10.2026

Рабочий исходник: ветка codex/watch-phone-bridge-20261024. Android 0.4.0+13 и часы 0.2.0. Прежнее состояние демо 0.1.0 см. историю Git. Текущие инструкции и ограничения — README.md и protocol.md рядом.

Прямой BLE GATT мост написан с opt-in, pairing, подтверждением часов, передачей выбранного потока и защитой команд. Телефонный таймер управляется через существующий обработчик; внешний Special Pie — только события, без выдуманных outgoing-пакетов.

Остаётся аппаратная квалификация: установка APK без очистки данных, Zepp preview/QR, pairing T-Rex 3 Pro, подтверждение на телефоне, реальные выстрелы и задержка, пять подключённых таймеров, потеря связи и поведение Android в фоне. Не выдавать тесты с подменой API за реальную связь. Сохранять пользовательские видео и данные. Публикация в Zepp Store не выполнялась.
