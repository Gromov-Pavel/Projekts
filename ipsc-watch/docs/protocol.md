# Bluetooth wire v1 (0.2.0)

Android: GATT Peripheral, часы: Central. opt-in + pairing/encryption + ручное подтверждение одного подключённого устройства на телефоне. При отключении доступ и command id сбрасываются; данные сохранённых проходов не редактируются.

UUIDs:
- Service dfc00001-8e4f-4d3c-9628-37cf53e51b18
- State dfc00002-8e4f-4d3c-9628-37cf53e51b18 (encrypted READ/NOTIFY, CCCD 2902)
- Command dfc00003-8e4f-4d3c-9628-37cf53e51b18 (encrypted WRITE)

До подтверждения разрешено только чтение синтетического кода сверки: phase=4, flags=4, count=0, run=шестизначный случайный код, revision=0, total=0, split=0xffffffff. Настоящие показатели и команды недоступны. Код обновляется на каждое подключение и проверяется при подтверждении на телефоне. После подтверждения revision всегда положительный.

State: ровно 20 байт, Little Endian. byte0 version=1. byte1 lower nibble phase: idle=0/preparing=1/running=2/finished=3/unavailable=4; bit4 phone, bit5 controllable, bit6 failed. uint16 count @2, uint32 run @4, uint32 revision @8, uint32 totalMs @12, uint32 splitMs @16 (0xffffffff если меньше двух выстрелов). Это полный снимок показателей; пропуск notification не теряет количество выстрелов. На часы не передаются MAC таймера, имена стрелков и видео.

После успешного чтения часы включают notifications; чтение раз в секунду служит heartbeat и восстановлением. При отсутствии подтверждённого чтения/уведомления 5 секунд данные помечаются устаревшими, команды отключаются. Старые версии и регресс счётчика/времени отвергаются. При новом run источником является только выбранный поток, revision растёт на протяжении включения моста.

Command: 12 байт. version=1 @0, op start=1/finish=2 @1, uint16 монотонный requestId @2, uint32 expectedRun @4, uint32 observedRevision @8. Последний revision — контекст наблюдаемого снимка; актуальность команды проверяется по run, фазе и доступности управления. Повтор requestId отвергается Android. Новый runId не может быть остановлен старой командой. Часы ожидают изменение фазы/прохода; receipt успешной записи не означает, что таймер запущен/остановлен. При ошибке телефон публикует failed с новой revision даже для повторной ошибки.

Phone source: экран телефонного таймера открыт и загружен; микрофон/подготовка/звук используют существующий код и настройки. Завершение сохраняет непустую серию. Старт не удаляет несохранённый результат. Сворачивание останавливает микрофон и отключает управление.

External source: read-only, исходные события выбранного TimerLink. Legacy Special Pie stop-пакет 0x18 принят как входящее завершение; команды в FFF2 не известны и не отправляются.

Лимиты: 10000 выстрелов, 24 часа, 32-bit run/revision (при переполнении нужна новая BLE-сессия). Никаких HTTP endpoints/облачного обмена результатами.
