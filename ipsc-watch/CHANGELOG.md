## 0.2.0 — 24.10.2026

- Демопоток заменён прямым BLE-клиентом Android GATT: поиск по UUID, pairing, уведомления и резервное чтение, контроль свежести и старых пакетов.
- Кнопка «Подключить / Старт / Отмена / Завершить», подтверждение команд состоянием телефона; успешная запись GATT не считается стартом/завершением.
- На внешнем таймере отображаются реальные входящие события, управление неподтверждённым протоколом заблокировано.
- Последние показатели сохраняются при разрыве; устаревание заметно, команды отключаются.
- Физическая установка и работа BLE не проверены. Нужны preview/QR и проверка пользователя на своих устройствах.

## 2026-10-24 — локальная сборка

Добавлена обязательная иконка и ссылка на неё в app.json. Все 8 тестов прошли; Zeus CLI 1.9.3 успешно собрал .zab для T-Rex 3 Pro 48 мм. appId остаётся тестовым; реальная связь Android → часы ещё не реализована. Пакет предназначен для разработки, не для Zepp Store.

# Изменения

## 0.1.0 — 2026-10-21
- Создан отдельный проект Zepp OS для T-Rex 3 Pro 48 мм (480×480).
- Главный экран: крупное время последнего выстрела, последний сплит, число выстрелов.
- Добавлены явно обозначенные демовыстрелы; при запуске реальные данные не имитируются.
- Два сохраняемых режима экрана: вся тренировка и только активный проход.
- Независимая модель снимков прохода с защитой от старых, повторных и некорректных пакетов.
- Добавлены тесты модели. Реальная связь Android → часы пока не реализована.
- APK существующего Android-приложения не менялся. Аппаратная проверка не выполнялась.
- Пройдено 8 Node-тестов модели и логики экрана с подменённым Zepp API; синтаксис JS проверен.
- Попытка сборки Zeus CLI 1.9.3 остановилась на загрузке каталога устройств Zepp: HTTP 502. Установочный пакет не получен.

## Передача на Mac — 2026-10-22
- Добавлены docs/MAC-HANDOFF.md с контекстом проекта и шагами продолжения, .gitignore.
- Подготовлена загрузка всего созданного в облаке проекта часов в отдельную ветку GitHub.
- Локальные Android-исходники и материалы с Mac в эту передачу не входят.
