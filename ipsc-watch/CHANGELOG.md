## 0.8.2 — 25.10.2026 — диагностика прямого соединения

- Убрана недостоверная подсказка, утверждающая связь таймера с телефоном. Таймаут теперь различает поиск сохранённого устройства, соединение, настройку профиля и подписку; ошибки профиля/подписки показывают полученный код.
- Перед подключением выполняется новый поиск строго сохранённого адреса с использованием полученного нативного адреса Zepp, по официальному примеру. Автоматическое системное спаривание отключено: используется обычное BLE-соединение к характеристикам таймера.
- Включены тесты точного выбора адреса, ошибки этапа подписки и отсутствия ложного старта. Прямой Start/Stop на реальном устройстве ожидает проверки.

## 0.8.1 — 25.10.2026 — поиск всех устройств и библиотека

## 0.8.0 — 25.10.2026 — прямое подключение к таймеру

- Шестерёнка → Подключение таймера: режимы «Через телефон» (по умолчанию) и «Напрямую к таймеру» с поиском и сохранением выбранного адреса.
- Прямой BLE-клиент использует официальный API Zepp 3.0: профиль, подписка, Start/Stop и отображение событий без телефона. Добавлено разрешение device:os.ble. Сохранён рабочий Zepp-мост.
- Готовность появляется после подписки, серия — после события таймера. При потере связи нет запуска телефонного таймера, автоматического повторного Start или ложного окончания по записи BLE.
- В прямом режиме один таймер, текущие метрики без синхронизации истории телефона. Внешняя задержка остаётся настройкой самого устройства.

## 0.7.0 — 25.10.2026 — случайная задержка

- В шестерёнке: «Задержка» → режим «Фиксированная / Случайная». Для случайной задаются нижняя и верхняя границы 0–60 секунд, по умолчанию 3–6 секунд; границы не пересекаются и сохраняются.
- Для каждого нового запуска телефонного таймера выбирается одно случайное значение в диапазоне с точностью до миллисекунды. Повторное нажатие во время ожидания не меняет выбранное значение.
- Прежняя фиксированная задержка сохранена и остаётся выбранной до явного переключения. Android 0.9.0 обновлять не требуется. Special Pie продолжает использовать собственную задержку.
