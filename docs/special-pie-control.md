# Special Pie M1A2: удалённые команды

Факты для совместимости установлены локальным статическим разбором обработчика M1A2 в установленном PractiScore Log 2.0.11 (versionCode 141). SHA-256 базового APK: `179faade527ec3e96fb9e3eb2ad557b24970094f893d078616234153a4b4b750`. APK, дизассемблированные файлы и пользовательские данные в репозиторий не включены. Это описание формата обмена, не копия исходников другого приложения.

| Действие | GATT | Байты |
|---|---|---|
| Старт | сервис FFF0, характеристика FFF2 | F8 F9 34 F9 F8 |
| Остановка | сервис FFF0, характеристика FFF2 | F8 F9 18 F9 F8 |

Команда имеет пять байтов и не содержит идентификатор серии. Уведомление о старте, уже поддерживаемое приёмником, содержит дополнительный байт серии и имеет шесть байтов. Эти направления нельзя смешивать.

Приложение разрешает команды только для распознанного legacy-протокола либо сохранённого устройства с ранее подтверждённым legacy-профилем, при наличии активного приёма и доступной для записи FFF2. Предпочтительна запись с подтверждением GATT; без подтверждения — только если характеристика поддерживает исключительно этот режим.

Успешная запись не означает, что серия началась: фаза часов меняется по входящему уведомлению. Старт автоматически не повторяется. Остановка, пришедшая во время записи старта, сохраняется с проверкой текущего прохода. При смене источника телефонный запуск отменяется.

Пакеты запуска не изменяют сохранённую конфигурацию таймера. Задержка Special Pie определяется самим таймером; задержка в шестерёнке часов пока относится к телефонному таймеру.

На собственном Special Pie M1A2 пользователя с Android 0.9.0+23 / часами 0.6.0 физически подтверждены старт и остановка командами часов без выстрелов. Найденный формат и этот прогон не доказывают совместимость со всеми прошивками M1A2/M1A2+ или точность регистрации выстрелов.
