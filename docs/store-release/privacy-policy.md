# Политика конфиденциальности «IPSC тренировОчка»

Редакция от 25 октября 2026 года для Android 0.14.1 и Zepp 0.9.1.

Разработчик: Павел Громов. Контакт по вопросам приложения и данных: pavgromov@gmail.com.

## Какие данные используются

Приложение обрабатывает введённые пользователем имена стрелков, упражнения, результаты, комментарии, выбранные видео и связанные с ними отметки выстрелов. Эти сведения нужны для журнала, расчёта тренировочных результатов, графиков и видеоразбора и хранятся локально. Для видео могут создаваться локальные копии, превью и экспортированные файлы. В приложении нет собственного облачного аккаунта, рекламного профиля или сервера сбора тренировок.

При включении телефонного таймера приложение с разрешения пользователя получает звук микрофона и вычисляет отметки звуковых событий. Поток обрабатывается в памяти, отдельная аудиозапись этого режима не сохраняется. Анализ выбранного видео использует его аудиодорожку локально. Отметки могут содержать ошибки и доступны для проверки пользователем.

Bluetooth используется для поиска и подключения выбранных таймеров и часов. Имена, адреса и служебные данные устройства нужны для соединения, управления, получения результатов и переподключения. На старых версиях Android поиск Bluetooth может требовать системного разрешения местоположения; приложение не использует его для построения истории перемещений.

Приложение часов сохраняет локальные настройки, выбранное устройство и служебные сведения о паре. При работе через телефон Zepp Side Service передаёт состояние и команды локальному серверу Android внутри телефона. Связь подтверждается пользователем, служебные ключи сохраняются локально. Видео через этот мост не передаются. В прямом режиме часы работают с выбранным Bluetooth-таймером без переноса истории в телефон.

## Разрешения и фоновые функции

Микрофон нужен только для соответствующих функций таймера. Bluetooth — для внешних устройств. Доступ к выбранным файлам — для импорта и видеоразбора. Уведомления и фоновые службы — для индикации и продолжения активной тренировки при сворачивании или блокировке. Начатую запись можно завершить штатной кнопкой; принудительная остановка процесса прекращает её. Отказ от разрешений ограничивает соответствующую функцию, ручной ввод результатов не требует микрофона или внешнего таймера.

## Передача данных

Приложение не отправляет результаты, пользовательские видео или звук микрофона на сервер разработчика для обучения либо аналитики. Пользователь сам выбирает экспорт и получателя через системное меню отправки. Получившие файл приложения и сервисы обрабатывают его по своим правилам. До отправки убедитесь, что вправе передавать сведения об участниках и изображения людей.

Магазины приложений, Android и платформа Zepp могут обрабатывать свои учётные, диагностические и технические данные по собственным политикам. Это не облачное хранение тренировок, организованное разработчиком. Обращение по email передаёт разработчику адрес отправителя и содержимое письма; не прикладывайте пароли, ключи соединения и чужие личные данные. Письмо используется для ответа и устранения описанной проблемы; запросить удаление переписки можно по тому же адресу.

## Хранение и удаление

Локальные результаты и копии файлов хранятся до удаления пользователем соответствующих данных. Приложение может сохранять локальную резервную копию журнала для восстановления после ошибки записи. Удаление строки не следует считать гарантированным уничтожением всех прежних локальных копий. Для полного удаления приватных данных Android-приложения можно очистить его хранилище системными средствами; предварительно экспортируйте нужные результаты. Отдельно удалите ранее экспортированные или переданные файлы из мест назначения. Настройки часов/Zepp удаляются средствами соответствующей платформы.

Автоматическое резервное копирование приватных данных Android средствами приложения отключено. Это не исключает существования пользовательских копий, системных особенностей производителя или ранее переданных экспортов.
