# Калибровка звука видео — 25.10.2026

Android 0.12.0+26. Использован новый пользовательский корпус для настройки существующего DSP-детектора. Обучение весов нейросети не выполнялось. Дообучение/измерение точности требует подтверждённой разметки стартов, выстрелов и отрицательных примеров.

## Подготовка данных

- Пять доступных папок, 333 файла видео, около 16.2 ГБ в исходном списке. Повтор одной ссылки учтён один раз; последняя недоступная ссылка пропущена по прямому указанию пользователя.
- 297 файлов скачаны с проверкой размера и SHA-256; получено около 1.809 часа звука. Для 36 файлов сервер вернул ошибку своего хранилища. Повторные попытки и проверка частичных загрузок не дали пригодных файлов.
- Все 333 исходных хеша различаются: точных дубликатов и переноса одного и того же файла между частями не обнаружено.
- Исходные записи, лица/имена, ссылки, звуковые дорожки и признаки хранятся локально вне публичного checkout. В Git включены только код, синтетические проверки и агрегированное описание. Никакая внешняя служба обучения эти материалы не получала.
- Признаки: исходная частота дискретизации, PCM16, окна 20 мс, целиком канал с наибольшей энергией, сетка тональных частот 1250–5000 Гц с шагом 50 Гц. Локальный FFT-расчёт соответствует сетке Goertzel приложения; это не аппаратная проверка декодера Android.

## Разделение по дням записи

| Часть | Доступные видео | Предложение старта до изменения | После изменения |
|---|---:|---:|---:|
| Настройка, три дня записи | 179 | 162 | 166 |
| Проверка неоднозначностей, отдельный день | 49 | 47 | 46 |
| Контроль, ещё один день | 69 | 62 | 63 |
| Всего | 297 | 271 | 275 |

Это **числа предложений детектора**, а не precision/recall и не доля правильно распознанных роликов. Добавлены пять предложений в ранее пропущенных случаях; в одном случае автоматический выбор снят, поскольку присутствуют два близких разных тона. Кандидаты обоих сигналов остаются доступны для подтверждения.

Числовые пороги подбирались на части настройки. На проверочной части выявлена неоднозначность, для которой добавлен запрос подтверждения. Контрольная часть прогонялась до и после этой защиты; считать это слепым итоговым benchmark нельзя. По контрольной части числовые параметры не подбирались. Разные видео одного дня могут иметь общие условия записи, поэтому разделение проведено целыми днями, а не случайными соседними роликами.

## Изменения детектора

- Короткое чистое тональное ядро от 100 мс может стать кандидатом. Более слабый протяжённый сигнал может сохранять короткое сильное ядро, даже когда хвост маскируется шумом.
- Общий более громкий фон позднее в ролике не должен скрывать тихий ранний сигнал.
- Порог кандидатов выстрелов зависит от шума записи; требуется резкий фронт. Стартовый тон и сильный импульс не поднимают базовый уровень настолько, чтобы скрыть следующий тихий звук. Существующее ограничение повторного импульса 150 мс сохранено.
- Близкие разные тоны рядом с коротким кандидатом требуют подтверждения пользователя. Отсутствующий/обрезанный сигнал не становится автоматически нулевой отметкой.
- Времена связанного внешнего таймера остаются приоритетными. Распознанные аудиозвуки остаются кандидатами; это может быть эхо, хлопок или выстрел соседнего стрелка. Считать принадлежность звука конкретному стрелку подтверждённой по этим признакам нельзя.

## Проверка и следующий этап

35 целевых тестов видео, синхронизации A/B, HUD, таймлайна и микрофонного детектора пройдены. Новые синтетические проверки покрывают короткий/замаскированный тон, одиночный спектральный выброс, конкурирующие тоны, изменение громкости, хвост импульса и тихий импульс после громкого сигнала. Анализ четырёх Dart-файлов без замечаний; APK собран.

Локально подготовлена таблица `needs_review.csv`: предложенные и отдельные подтверждаемые отметки. Поля подтверждённых стартов/выстрелов оставлены пустыми, статус всех строк — `unreviewed`; псевдоразметка не выдана за ответы человека.

Для воспроизведения числового прогона на локальных признаках: `dart research/evaluate_audio.dart FEATURES OUTPUT.json [SPLIT]`. CLI использует непосредственно production-реализацию Dart. Исходный корпус и персональная таблица в публичный репозиторий не входят.

Точность на реальных размеченных проходах и работа нового анализа на физическом телефоне отдельно ещё не квалифицированы. Детектор микрофона телефона не дообучался на сжатом звуке видео: его входные условия отличаются.
