# Автоматическое восстановление связи

Android 0.11.0+25 / часы 0.9.0. Восстановление соединения не запускает и не останавливает таймер. Подключается только ранее выбранное устройство.

## Часы напрямую

- При потере BLE-соединения повтор начинается через 2 секунды; после неудач пауза увеличивается до 4, 8, 16, максимум 20 секунд. Каждый этап поиска/соединения/профиля/подписки имеет отдельный таймаут 20 секунд.
- Последний полученный результат остаётся на экране. Кнопки Start/Stop до восстановления приёма недоступны. После подписки приём готов автоматически; код телефона не нужен.
- Старые команды и намерение остановки после обрыва отменяются. Успешная подписка не считается событием старта и не обнуляет последний результат.
- Уход с рабочего экрана в настройки или закрытие приложения отменяет повторы. При возвращении на рабочий экран начинается новое подключение сохранённого таймера. Восстановление выполняется, пока рабочий экран приложения открыт; на время повторов он удерживается активным, что расходует батарею.

## Android

- Для сохранённого таймера должна быть включена настройка «Подключаться автоматически». После непреднамеренного разрыва первый повторный поиск планируется через 2 секунды. Далее работает существующий поиск раз в 20 секунд, без параллельных попыток подключения.
- Возврат Bluetooth телефона во включённое состояние также запускает поиск. Новые разрешения при автоматическом поиске не запрашиваются.
- Фоновый сервис приёма не выключается только из-за временной потери последнего таймера, пока ожидается восстановление. Если Android принудительно остановил сам процесс, фоновое переподключение этим не гарантируется; после открытия приложения загружаются сохранённые таймеры.
- Ручное «Отключить» приостанавливает подключения к этому таймеру до следующего запуска приложения. Выключение автоподключения сохраняется. Это позволяет освободить таймер для часов без конкуренции двух клиентов.

## Что происходит с проходом

Если связь пропала во время прохода, телефон сохраняет уже полученную часть с признаком `partial`. На часах остаются последние время, число выстрелов и сплит с предупреждением о неполном проходе.

После восстановления связи приложение ждёт событие старта новой серии. У Special Pie legacy уведомление отдельного выстрела не содержит идентификатора прохода. Поэтому продолжать дописывать такие уведомления в старый проход небезопасно: за время отсутствия связи на таймере мог начаться другой проход. Старые и новые данные не объединяются по одному лишь возрастанию времени.

**Дозагрузка пропущенных выстрелов/истории и продолжение прерванного прохода в этой версии не реализованы.** Для этого требуется отдельно проверить чтение истории конкретной прошивки и сопоставление сохранённых серий. Наличие повторного Bluetooth-соединения не выдаётся за восстановление всех результатов.

## Проверка

1. Приём с выбранного таймера готов; приложение открыто. Для прямого режима часов телефон освободил соединение.
2. Выключить Bluetooth на самом таймере примерно на 10 секунд и снова включить. Без выстрелов и без нажатий «Подключить» / Start / Stop.
3. Дождаться автоматического поиска и готовности. У таймера не должен самопроизвольно прозвучать стартовый сигнал.
4. Отдельно проверить потерю связи после начала серии: предыдущие полученные данные остаются, отмечены неполными; следующая явно запущенная серия начинается с нуля.

Синтетические тесты проверяют повторы/отмену/сохранение/отсутствие повторных команд. Аппаратная проверка радиуса, энергосбережения и этой новой версии описывается отдельно в BUILD-CHECK.md.
