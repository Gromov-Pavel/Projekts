# Проверка предупреждения Vivo — 25.10.2026

## Статус: не устранено

Vivo ранее показывал «Обнаружен опасный вирус. Обнаружено вредоносное приложение. Оно может привести к утечке данных и финансовым потерям. Немедленно удалите его». Название семейства/движка/правила не получено. После установки 0.12.2 пользователь подтвердил: предупреждение осталось. Объявлять его ложным срабатыванием или считать исправленным нельзя.

## Сделано в 0.12.2+28

- Вместо debug APK подготовлен ARM64 release APK. Внутри есть AOT libapp.so, нет kernel_blob.bin; debug/JNI-debug отключены.
- Удалено неиспользуемое CAMERA. Bluetooth, микрофон, уведомления и локальный мост часов сохранены.
- Запрещены автоматический Android backup и перенос приватных файлов/настроек через data-extraction-rules. Ручной экспорт сохранён. Исходящий HTTP запрещён; входящий Zepp-сервер по-прежнему привязан к 127.0.0.1 и требует подтверждения пары, ключа/сессии и свежего ID команды.
- Release требует IPSC_SIGNING_PROPERTIES с путём к приватному файлу настроек. Секреты/keystore хранятся вне репозитория. Автоматического fallback на debug signing нет; агрегированные задачи тоже проверяются перед упаковкой.
- Чтобы обновить установленное приложение без удаления истории, сохранены прежние ключ и сертификат с DN Android Debug. Ключ импортирован в отдельный защищённый PKCS12 с новым паролем. Это не смена сертификата и не независимая репутация издателя. Переименование или смена package ID для обхода детекции не выполнялись.

- assembleRelease и lintRelease успешны: 0 Error/Fatal, 12 предупреждений (версии инструментов/зависимостей, совместимость атрибутов API, существующий wakelock без timeout и рекомендации кода).
