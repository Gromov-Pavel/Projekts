# Таймеры: библиотека и границы поддержки

Состояние на 25.10.2026. Исследованы установленные PractiScore Log 2.0.11 (141) и Atlima: только код приложения, без чтения их баз тренировок. Чужие APK, исходники, разбор бинарников и данные устройств в репозиторий не включены. Реализации написаны независимо по фактам обмена. Тестовые пакеты в `fixtures/timer-protocol-vectors.json` синтетические, не аппаратные записи.

## Реализовано в Android 0.10.0 и часах 0.8.3

| Семейство | Приём | Команды | Ограничения проверки |
|---|---|---|---|
| Special Pie M1A2 / M1A2+ legacy | Начало, времена, конец; FFF0/FFF1 | Старт/Стоп FFF2 | Старт/Стоп через телефон физически подтверждены пользователем ранее. История проверки прямого режима: первый поиск 0.8.0 не обнаружил устройство; 0.8.1 нашла свой таймер, соединение не состоялось; 0.8.2 установила соединение, но не получила готовность профиля. После обновления до 0.8.3 пользователь проверил прямой режим и подтвердил: «все заработало». Точность выстрелов/сплитов отдельно не измерялась. Совместимость каждой прошивки M1A2+ не заявляется. |
| SG Sport / GO API 3 | Сессия, индекс, время в миллисекундах | Start/Stop | Только проверка опубликованного формата и тестовых пакетов. ACK команды не является событием начала серии. Старый SST09714 не приравнивается к API 3. |
| ProTimer BT / PT Link v2 | JSON string-started / shot / string-stopped | start-string / stop-string | Фрагментация JSON проверена. Ревизия 1 через Battery Service отдельно не включена. На устройстве не проверено. |
| RangeTech | BEEP, SHOT, BUTTONUP | B000000 / C000000 | Обрабатываются полные ASCII-уведомления, как в исследованном клиенте. LSHOT (история) исключён из live. Подтверждение удалённой остановки по событию требует проверки на таймере; таймаут не подменяется успешной остановкой. |
| AMG COMM / PS / SK с Nordic UART | StartStop и Screen с идентификатором серии | COM START / COM STOP | Разбираются полные бинарные уведомления, а не произвольные фрагменты. Push-режим устройства должен уже передавать экран. Настройки PUSH/PAR автоматически не меняются. Не реализованы запрос истории и дополнительные события SK. На устройстве не проверено. |

Это пять реализованных форматов, а не обещание работы всей линейки на любом оборудовании. Для SG, ProTimer, RangeTech и AMG необходима квалификация на соответствующем устройстве до доверенного зачётного использования. Поиск по общей Nordic UART/FFF0 UUID без имени не доказывает модель таймера.

## Полный обнаруженный каталог и ещё не реализованные варианты

| Источник | Семейство / вариант | Что требуется для включения |
|---|---|---|
| PractiScore Log | Special Pie M191 | Проверить настройки и события на устройстве; наследование команды не доказывает совместимость всех кадров. |
| PractiScore Log | AMG COMM, AMG PS, AMG SK / SK Pro | Общий базовый формат реализован выше; дополнительные функции/прошивки требуют отдельных пакетов. |
| PractiScore Log | Kestrel KST | Доработать многоканальную подписку событий/значений и синхронизацию строк; подтвердить формат времени и команды. Найденные константы не используются как неподтверждённые команды. |
| PractiScore Log | Edge | Проверить CRC, обрамление, варианты уведомлений и данные серии. |
| PractiScore Log | ShooterKun SK | Проверить ASCII-записи сессии, номера, времени и направление характеристик. |
| PractiScore Log + Atlima | SSP / SSP 6C18 | Уведомления содержат время без явного старта/конца. Команда R связана со сбросом/локальной записью, её нельзя выдавать за аппаратный звуковой старт. |
| PractiScore Log | ProTimer v1 | Совмещённая характеристика 2A19 в сервисе 180F требует отдельного, ограниченного именем профиля и проверки. |
| Atlima | SG SST09714 | Старый формат требует отдельного профиля; не включён в SG API 3. |
| Atlima | Special Pie SPM1A2 | Базовые кадры Special Pie реализованы; покрытие каждой прошивки не подтверждено. |
| Atlima | V2CM | Найдены FFE0/FFE1/FFE2 и управление Special Pie-подобными кадрами. Перед включением нужен отдельный декодер высоких байтов секунд/идентификации кадров и аппаратный образец. |
| Требования группы | CED7000 с RF-модулем | Это RF, не BLE. Для часов/телефона нужен совместимый аппаратный радиомост и описание его интерфейса. Само разрешение Bluetooth не заменяет мост. |

Неизвестный формат в Android остаётся диагностическим: он не создаёт выстрелы и не получает случайные команды. На часах ручной выбор модели применяется только после явного выбора устройства пользователем. Неподдержанные строки каталога не добавлены в список работающих протоколов.

## Прямой режим часов

1. На телефоне отключить таймер в IPSC и других приложениях. Если он не начал рекламу, выключить/включить Bluetooth на самом таймере.
2. Часы: шестерёнка → Подключение таймера → Напрямую к таймеру → Поиск.
3. Выбрать свой таймер. Показаны и устройства без узнаваемого имени; для них вручную выбрать протокол. Не выбирать чужие устройства.
4. После выбора адрес сохраняется локально на часах. Следующее открытие приложения подключается к нему без кода телефона. При ошибке повторить нижней кнопкой; бесконечных стартов и автоматического переключения на телефон нет.
5. Большая зелёная СТАРТ запускает выбранный таймер; красная Стоп завершает. Доставка записи BLE не означает начало серии: экран меняется по фактическому уведомлению таймера.

Одновременно подключён один прямой таймер. 0.8.3 показывает текущий проход; перенос автономных проходов в историю телефона пока не реализован. Чтобы записывать тренировку в телефон, использовать прежний режим Через телефон. Фиксированная/случайная задержка часов применяется к таймеру телефона; внешний таймер сохраняет собственную задержку.
